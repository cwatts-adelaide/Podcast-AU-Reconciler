Podcast ↔ AU Reconciler

mapping_key join

Joins a raw podcast delivery export against an AU-model export, rebuilds the S3 upload schema, and spot-checks the join before you ship it.

Where this tool fits in the process

Before this tool

  1. Reformat the client file and upload it as [friendly name]+manual+[campaign id]+[date YYYYMMDD].csv to adelaide-fs-audio
  2. Wait for the success notification in #audio notifications
  3. Pull the AU data from the Looker explore

Field reference

  • ad_type: Host-read, Produced
  • pod_position: Pre, Mid, Post
  • Both are matched case-insensitively, but the tool will flag anything outside this set under "Other risks"
  • placement_id is required on every row

After this tool

  1. Download output_schema.csv below
  2. Upload it to adelaide-fs-omnichannel / domain_report

1. Raw delivery export

The podcast_external_file-style export — one row per placement/show/date, with impressions.

2. AU data export

The au_data-style export — one row per mapping_key, carrying avg_au and adelaide_campaign_id.

3. Output filename

Names the downloaded file as [client]_podcast_domain_report_[MMDDYYYY].csv — matches the convention for the omnichannel upload.
